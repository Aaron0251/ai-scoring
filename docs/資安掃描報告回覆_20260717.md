## 三、OS 套件層級漏洞之處理方式：更換基底映像檔

### 3.1 問題本質

其餘漏洞（含 CRITICAL 3 筆：perl ×2、zlib；HIGH 4 筆：attr、acl、perl ×2）均為
Debian 作業系統套件之已知漏洞，**Debian 官方目前均無修補版本可安裝**
（`apt-get upgrade` 無法取得修復）。其中多筆（如 CVE-2005-2541 tar、
CVE-2011-3374 apt、CVE-2010-4756 glibc 等）為 Debian 官方明確標記
**won't-fix（永不修復）** 或上游認定非漏洞（disputed）之項目，
持續等待修補並不可行。

### 3.2 處理方式

已將後端基底映像檔自 `node:22-slim`（Debian 12）更換為 `node:22-alpine`。
Alpine 使用 musl / busybox 而非受影響之 Debian 套件，上述漏洞因套件不存在而
整批消除（非隱藏或忽略），且 Alpine 社群對 CVE 之修補速度較快。

### 3.3 驗證結果（2026-07-17）

- GCP Container Analysis 重新掃描結果：**0 筆漏洞**（原 78 筆 → 0 筆）
- 新版映像檔已完成部署並通過部署管線全部關卡，流量已切換至新版本
- 服務功能驗證正常（API 回應符合預期）
- 服務網址：https://fme-ai-scoring-zkc6hnkahq-de.a.run.app
